# School Management System

A simple School Management System built with **Python** and **Object-Oriented Programming (OOP)**.

## Features

* Create students
* Create teachers
* Create courses
* Enroll students in courses
* Display students enrolled in a course
* Manage student grades
* Track total students, teachers, and courses

## OOP Concepts Used

* Classes and Objects
* Inheritance
* Encapsulation
* Polymorphism
* Properties and Setters
* Class Variables
* Instance Variables
* Methods
* `super()`

## How to Run

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd School-Management-System-OOP
```

Run the program:

```bash
python school_management.py
```

## Note

This project is a console-based application created to practice and demonstrate Object-Oriented Programming concepts in Python.
